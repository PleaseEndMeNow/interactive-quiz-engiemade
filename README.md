# Interactive Quiz Application

## This is a standalone general knowledge quiz application built using Python and the Tkinter library.

---------------------------------------------------------------------------------------------------------------------------

## How It Works:

Standalone Executable: This program is packaged as a single executable file (.exe) using PyInstaller. You do NOT need to have Python installed on your computer to run this application.

Simple Interface: The application runs in a small graphical window.

Real-time Score: A separate, smaller window tracks your score and the current question number in real-time.

Quit Mechanism: The "Quit Quiz" button uses a two-stage confirmation (Quit? -> Quit???) to prevent accidental closure.

---------------------------------------------------------------------------------------------------------------------------

## How to Run:

Double-Click: Simply double-click the interactive_quiz.exe file.

Initial Prompt: The quiz will start by asking you a few introductory questions in the console (black command window) to ensure you are ready to play.

Start Quiz: Once you confirm you want to play, the graphical quiz window will open.

---------------------------------------------------------------------------------------------------------------------------

## Troubleshooting:

Q: The quiz window disappeared!

A: Check your taskbar for a window named "Quiz Status" or "Question X/Y". Sometimes the operating system hides new windows behind others.

Q: I hit the 'X' button on the question dialog.

A: The quiz is designed to prevent accidental exits. Clicking the 'X' will pop up a dramatic warning message and ask the question again. Use the dedicated Quit Quiz button to exit gracefully.
